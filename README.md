# 33⅓

Лонгрид о том, почему в эпоху стриминга люди снова покупают виниловые пластинки.

Инструменты ИИ в разработке

## Библиотеки

- [Lenis](https://github.com/darkroomengineering/lenis) 1.1.20 (MIT) — плавная прокрутка. Файл `javascripts/lenis.min.js`, стили `stylesheets/lenis.css`.
- [GSAP](https://gsap.com) 3.12.5 с плагином Observer — «цепочка шагов» при прокрутке. Файлы `javascripts/gsap.min.js` и `javascripts/Observer.min.js`. Бесплатная [стандартная лицензия GSAP](https://gsap.com/standard-license).
