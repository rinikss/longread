# 33⅓

Лонгрид о том, почему в эпоху стриминга люди снова покупают виниловые пластинки.

В работе над кодом использовался ИИ-ассистент **Claude** (модель Claude Opus 5.5, Anthropic).

Концепция, структура лонгрида, тексты, дизайн и все визуальные решения — мои.
Ассистент помогал с технической реализацией:

- скриптами анимаций по скроллу и плавной прокрутки;
- отрисовкой свечения линий на canvas;
- адаптацией вёрстки под планшет и мобильные устройства;
- поиском и исправлением ошибок в разных браузерах;

Весь код я проверяла, правила и настраивала вручную под свой макет.

## Библиотеки

- [Lenis](https://github.com/darkroomengineering/lenis) 1.1.20 (MIT) — плавная прокрутка. Файл `javascripts/lenis.min.js`, стили `stylesheets/lenis.css`.
- [GSAP](https://gsap.com) 3.12.5 с плагином Observer — «цепочка шагов» при прокрутке. Файлы `javascripts/gsap.min.js` и `javascripts/Observer.min.js`. Бесплатная [стандартная лицензия GSAP](https://gsap.com/standard-license).
